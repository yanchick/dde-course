# Программа курса

Курс «Инжиниринг данных» знакомит студентов с полным жизненным циклом работы с данными: от сбора и очистки до хранения, оркестрации и мониторинга. Большая часть материала закрепляется лабораторными работами и итоговым проектом, приближенным к реальным задачам инженера данных.

!!! note "Нумерация"
    Колоды 1–7 тематически соответствуют лекциям 9–15 программы. Колода 8 (BI) и колоды 9–10 (AI-агенты) выходят за рамки программы из 16 лекций.

## Два уровня обучения

Курс состоит из двух последовательных уровней. Можно выбрать один из двух треков.

| Трек | Содержание | Для кого |
| --- | --- | --- |
| **Только базовый уровень** | 8 лекций по основам Python, работы с данными (pandas), SQL и визуализации | Студенты без опыта программирования или с минимальным опытом |
| **Базовый + продвинутый уровень** | 16 лекций: базовый уровень + архитектура данных, ETL/ELT-пайплайны, Airflow, Data Lakes/Warehouses, DevOps | Студенты с уверенным знанием Python и базовым знанием SQL |

## Базовый уровень (лекции 1–8)

**Пререквизиты:** уверенное владение компьютером; понимание основ математики и статистики — желательно, но необязательно.

| № | Тема | Содержание |
| --- | --- | --- |
| 1 | Введение в инжиниринг данных и основы программирования | Что такое данные, роль инженера данных, установка Python, основы синтаксиса |
| 2 | Основы программирования на Python | Условные операторы и циклы, списки/словари/кортежи, функции и модули, работа с файлами |
| 3 | Знакомство с данными | Типы и форматы данных (CSV, JSON, XML), pandas и DataFrame |
| 4 | Простой сбор данных | Источники данных, работа с API, этика сбора |
| 5 | Базовая очистка данных | Проблемы в данных, пропущенные значения, дубликаты, pandas на практике |
| 6 | Простая предобработка данных | Типы данных, фильтрация и сортировка, группировка, новые столбцы |
| 7 | Основы хранения данных | Что такое БД, введение в SQL, SQLite через Python |
| 8 | Визуализация и представление результатов | matplotlib/seaborn, отчёты, документация, итоговый проект |

## Продвинутый уровень (лекции 9–16)

**Пререквизиты:** уверенное владение Python (переменные, функции, классы, работа с библиотеками), опыт работы с pandas и numpy, базовые знания SQL, понимание основ баз данных.

| № | Тема | Содержание |
| --- | --- | --- |
| 9 | Архитектура систем обработки данных | Lambda/Kappa, микросервисы, облака (AWS/GCP/Azure), Docker и Kubernetes |
| 10 | Продвинутый сбор данных | REST API и GraphQL, Scrapy, потоковая обработка, большие файлы и распределённые системы |
| 11 | Продвинутая очистка и валидация данных | Автоматизация очистки, статистические методы аномалий, Great Expectations/Pandera, профилирование |
| 12 | Сложная предобработка и трансформация | Feature engineering, временные ряды, NLP, изображения и мультимедиа |
| 13 | Системы разметки и аннотации данных | Платформы разметки, активное обучение и semi-supervised, контроль качества, автоматизация разметки |
| 14 | ETL/ELT-пайплайны и оркестрация | Airflow, дизайн надёжных пайплайнов, мониторинг и логирование, обработка ошибок и восстановление |
| 15 | Современные хранилища данных | Data Lakes vs Data Warehouses, колоночные БД (ClickHouse, BigQuery), NoSQL (MongoDB, Cassandra), HDFS и S3 |
| 16 | Мониторинг, тестирование и DevOps | Data observability, тестирование пайплайнов, CI/CD, безопасность и GDPR |

## Как устроен курс

- **Лекции** дают теорию и разбор инструментов; опубликованные колоды доступны в разделе [«Лекции»](lectures/index.md).
- **Семинары** продвинутого уровня — практикумы на стенде Sputnik-Mart: от архитектуры сервисов до сквозного прогона. Материалы и порядок сдачи — в разделе [«Семинары»](seminars/index.md).
- **Проект** — командная работа над аналитической платформой с защитой перед жюри. Условия и критерии — на странице [«Проект»](project.md).
- **Самопроверка** помогает понять, готовы ли вы пропустить базовый уровень: [опросник](self-check.md).
