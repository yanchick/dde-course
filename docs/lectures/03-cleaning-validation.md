# Продвинутая очистка и валидация данных

## О чём лекция

- Автоматизация очистки: таксономия грязных данных, декларативный подход, идемпотентность, batch и streaming.
- Статистические методы аномалий: z-score и его модификации, IQR, расстояние Махаланобиса, DBSCAN, Isolation Forest, One-Class SVM.
- Валидация данных: data contracts, schema evolution, Great Expectations, Pandera, Pydantic, Cerberus и Deequ.
- Профилирование: pandas-profiling и Sweetviz, профилирование больших данных, дашборд качества и статистические тесты дрейфа.
- Data observability: пять столпов, lineage и жизненный цикл качества данных.
