## Как читать слайды

- **HTML** открывается в браузере и работает без интернета: это готовая презентация Marp.
- **PDF** удобен для печати и просмотра на планшете.
- **Исходник** — Markdown с frontmatter Marp; из него собираются обе версии командой `make slides`.

Альтернативные редакции колод хранятся в локальном архиве курса и в репозиторий не входят.
