# Продвинутый сбор данных

## О чём лекция

- REST API: пагинация, фильтрация, сортировка, аутентификация OAuth 2.0, коды ответов, ретраи и rate limiting.
- GraphQL: структура запроса, преимущества и подводные камни, работа из Python.
- Web scraping: архитектура Scrapy, XPath и CSS-селекторы, прокси и User-Agent, Scrapy против Selenium, этика и право.
- Потоковая обработка: Kafka, топики и партиции, продюсеры и консьюмеры, Kafka Connect, Flink и Spark Streaming.
- Большие файлы и распределённые системы: чтение чанками, Parquet, HDFS, Dask и современные табличные форматы.
