# Частые вопросы

### Где взять стенд для семинаров?

Стенд — репозиторий [Sputnik-Mart](https://github.com/yanchick/Sputnik-Mart). Склонируйте его рядом с материалами курса:

```bash
git clone https://github.com/yanchick/Sputnik-Mart.git ~/Sputnik-Mart
cd ~/Sputnik-Mart
cp .env.example .env
uv sync --all-packages --dev
```

Путь к репозиторию передаётся скриптам через переменную `SPUTNIK_REPO`.

### Нужен ли Docker?

Зависит от семинара:

- **Семинары 1–3** — да. Первый работает с профилем `base`, второй и третий — с `adv`.
- **Семинары 4–9** — нет. Задания вычислительные: код репозитория импортируется, а хранилища и сервисы моделируются детерминированными структурами.
- **Семинар 10** — материалы готовятся.

### Как запускать скрипт?

Из терминала, из корня репозитория курса:

```bash
export SPUTNIK_REPO=~/Sputnik-Mart
cd "code/seminars/01_architecture"
uv run --project "$SPUTNIK_REPO" python seminar_01.py
```

Часть семинаров требует дополнительных пакетов, например `--with httpx --with pandas`. Точная команда указана в разделе «Как запускать» на странице семинара.

### Можно ли работать в JupyterLab?

Да. Скрипты — IPython-скрипты: ячейки разделены `# %%`, markdown-ячейки помечены `# %% [markdown]`. JupyterLab, VS Code и PyCharm понимают этот формат; скрипт также запускается как обычный `.py`. Для заданий с Kafka и Scrapy надёжнее терминальный запуск: event loop и Twisted-реактор в ядре Jupyter могут конфликтовать.

### Как сдавать работу?

Заполнить `TODO` в студенческом скрипте, добиться вывода `run_checks()` без `FAIL` и заполнить `ANSWERS`. Преподаватель задаёт 2–3 вопроса по таблице, эксперименту или выводам — проверяется понимание, а не только зелёный вывод.

### Где полные решения?

Полные решения доступны преподавателю. Они не публикуются в репозитории курса: задания проверяются по `run_checks()` и устным вопросам, а не по совпадению с готовым файлом.

### Сколько длится семинар?

Обычно 90 минут: 5 минут на вход и проверку стенда, 15 — на разбор, 15 — на демо, 40 — на самостоятельную работу, 10 — на дебрифинг и 5 — на сдачу. Семинар 3 (Event-системы) занимает 90–120 минут.

### Что делать, если профиль `base` не поднимается?

На старых коммитах Sputnik-Mart `catalog` падает с `ModuleNotFoundError: No module named 'service_client'` — это дефект BUILD-1. Патч лежит в [`code/seminars/01_architecture/BUILD-1.patch`](https://github.com/yanchick/dde-course/blob/main/code/seminars/01_architecture/BUILD-1.patch). В актуальной ветке `master` зависимость уже объявлена, патч не нужен.
