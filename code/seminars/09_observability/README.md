## Что внутри

| Файл           | Кому          | Что                                      |
| -------------- | ------------- | ---------------------------------------- |
| `seminar_09.py` | студенту      | задания с `# TASK` и `TODO`              |
| `README.md`     | обоим         | запуск, ожидаемый результат, диагностика |

Оба файла — IPython-скрипты: ячейки разделены `# %%`, markdown-ячейки —
`# %% [markdown]`. Открываются в JupyterLab, VS Code, PyCharm и запускаются
как обычный Python-скрипт.

## Подготовка стенда

```bash
git clone https://github.com/yanchick/Sputnik-Mart.git ~/Sputnik-Mart
cd ~/Sputnik-Mart
uv sync --all-packages --dev
```

!!! info "Docker, Prometheus и Grafana не нужны"
    Метрики — детерминированная серия тех же имён, что отдаёт Prometheus:
    `sputnik_consumer_lag`, `sputnik_data_freshness_seconds`,
    `sputnik_quality_score`. CI читается из `.github/workflows/ci.yml`, если
    репозиторий рядом, иначе берётся встроенный снимок. Живой `429` требует
    прокинуть `RATE_LIMIT_*` в compose — backlog **SRV-26**; здесь он
    моделируется клиентом.

## Ожидаемый результат

1. **Метрики.** 180 минут; базовый лаг 25–40, в окне 60–89 добавляется 750.
2. **9.1.** Одно окно `60–89`, 30 минут, `max_lag=788` на минуте 85,
   `degraded_minutes=30`; свежесть выше SLA ровно 30 минут, минимум
   `qualityScore=0.8587`.
3. **9.2.** Пять кейсов, все зелёные; убиты три мутанта: `empty_crash`,
   `swapped`, `ignores_zero`.
4. **9.3.** Успешный сценарий: 3 попытки, задержки `[1.0, 2.0]`.
   Исчерпание: 5 попыток, задержки `[1.0, 2.0, 4.0, 8.0]`.
5. **9.4.** Семь job'ов: `lint`, `unit`, `coverage`, `contract`,
   `contract-lint`, `image-build`, `release-gate`. Падение `unit` даёт
   `exit_code=1`, `failed="unit"`, `passed=["lint"]`. Переименование
   `stationId` → `station_id` даёт `ok=False`, `removed=["stationId"]`.
6. **9.5.** До маскирования 10 находок (6 email + 4 телефона), после — 0;
   `userId` сохранён; 10 строк остались на месте.
7. **Эксперимент.** Без маски — 10 находок, гейт блокирует; с маской — 0,
   гейт пропускает.
8. Итог: `Итог: 7/7 проверок пройдено`.

!!! note "Почему мутанты, а не «покрытие 80%»"
    Покрытие говорит, сколько строк выполнилось, но не сколько ошибок поймано.
    Мутант — это намеренно сломанная функция; если тесты её не заметили, они
    проверяют счастливый путь. Три мутанта здесь соответствуют трём типичным
    регрессам: падение на пустом входе, перепутанные границы и потеря нулей.


!!! note "`Retry-After` важнее backoff"
    Экспоненциальный backoff — разумная догадка, но сервер прямо говорит,
    сколько ждать. Поэтому задержка — максимум из двух значений, а не сумма.
    Потолок 8 секунд защищает от «уснуть на час» при серии `429`.


!!! note "«Зелёный CI» не значит «нет PII»"
    Гейт ловит только то, что проверяет. Эксперимент показывает: без явного
    сканера утечка проходит. Поэтому `find_pii` — такой же обязательный шаг,
    как unit-тесты.


## Диагностика

| Симптом                                             | Что делать                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| 9.1: окон больше одного                             | порог 500; проверьте, что не сравниваете свежесть вместо лага              |
| 9.1: `max_minute` не внутри окна                    | берите пик по всей серии, но проверка ждёт пик именно в деградации         |
| 9.2: мутант `ignores_zero` выжил                    | добавьте кейс со значением `0.0`                                           |
| 9.2: мутант `swapped` выжил                         | нужен кейс, где min ≠ max, а не одно значение                              |
| 9.3: задержки `[2, 4]`                              | `Retry-After` и backoff берутся через `max`, а не `+`                      |
| 9.3: задержка 16 секунд                             | забыт `min(max_delay, ...)`                                                |
| 9.4: jobs пустой                                    | парсер ждёт `jobs:` и отступ ровно два пробела                             |
| 9.4: `release-gate` не последний                    | job'ы читаются в порядке объявления, не по алфавиту                        |
| 9.5: после маски остались находки                   | замените email на `***@***`, телефон на `***`, проверьте оба поля          |
| 9.5: потерян `userId`                               | маскируются только значения, ключи и `userId` не трогаются                 |
| Эксперимент: гейт пропускает грязную выгрузку       | `ci_blocks_unmasked` должен быть `count > 0`                               |
| Кириллица в консоли ломается                        | `export PYTHONIOENCODING=utf-8`                                            |
| Студенческая версия печатает `0/7`                  | это ожидаемо до выполнения заданий; смотрите строки `Задание 9.x не выполнено` |
